# Hoggie tier list

The standalone `/tier-list` campaign uses the site's Explorer window, OSButton, theme tokens, and container breakpoints. Each time the page opens, it revalidates the live `https://brand.posthog.com/catalog.json` published with the brand package. New illustrations and variants appear without a website redeploy or package install. Names, search tags, and tier colors all come from that catalog; illustrations use the matching canonical PNG URLs on brand.posthog.com. Tier colors come from that catalog, and the logo uses the website’s official generated brand assets. There is no bundled catalog. Loading shows a status message; network errors, invalid catalogs, and requests taking longer than five seconds show a Try again button. Retrying fetches the live catalog again. Saved drafts are not overwritten while the catalog is unavailable. Saved/shared rankings restore after the live inventory loads, so links containing newly published hoggies survive. An already-open page picks up later releases when reopened or refreshed. This does not change the version of `@posthog/brand` used elsewhere on the website. All catalog entries are available in the searchable horizontal tray. The editor fills its app window: the five tier rows fit the available height without a vertical board scrollbar, while the tray and finish control remain visible. Crowded maker rows scroll horizontally with hidden scrollbars; completed results wrap all ranked artwork for export. The title is fixed to “My hoggie tier list” and the title, logo, and make-yours footer render only in the completed result and downloaded image. Browse the tray with horizontal scrolling, the mouse wheel, arrow buttons, or keyboard scrolling. Only ranked entries appear in the result. Completion switches to a photobooth-style sharing screen with a centered “Share with your friends” heading, a single Download image CTA above the image preview. No social links, copy-link controls, or additional CTAs appear on the completed screen. The maker title and instructions are hidden in that view; the image retains its own title and branding for export.

Hover or keyboard-focus any editable hoggie for a large, named preview using the site’s shared Tooltip. The preview is portaled outside the tray to avoid clipping and is suppressed during dragging.

Drag illustrations between tiers or onto another illustration to insert before it. Ranking uses drag and drop only. Pointer drops use the cursor position; keyboard drops use the dragged tile’s bounds. Keyboard users can press Space to pick up a focused hoggie, move it with arrow keys, and press Space to drop it; Escape cancels the drag. Each ranked hoggie has a visible X button that immediately returns it to the tray without starting a drag or changing other rankings. Users can finish after ranking a single hoggie.

Drafts are saved locally when storage is available. Drafts use a versioned title and tier membership, with no server or account. Existing shared URL fragments remain readable for backwards compatibility. Unknown and duplicate slugs are ignored; invalid payloads show an error.  Completed artwork uses the official SVG illustrations. PNG downloads render directly at up to 4800px wide (capped at 16 megapixels for unusually tall rankings) using an SVG transform at export resolution, rather than enlarging the small preview raster. A separate offscreen 1200px layout makes output dimensions independent of the app window or phone size, and is removed after export. Completed tiles are larger for legible illustration detail; compact maker tiles stay unchanged. The PNG retains the fixed title, logo, all ranked hoggies, and make-yours footer. Export failures show a retry message.

Run catalog and state tests with `node --disable-warning=MODULE_TYPELESS_PACKAGE_JSON --test src/components/TierList/catalog.test.ts src/components/TierList/state.test.ts`.
