# Context Warehouse

This guide has two kinds of page. Some answer a question straight away, as a saved insight that
joins PostHog to Stripe, your CRM, or your support desk. Others build a model the whole team
shares, set up once.

## Where to start

Have a question about revenue, churn, or leads right now? Pick one from **Ask a quick
question**. Each one builds and saves a real insight end-to-end.

Building something durable instead? Start with
[Warehouse foundations](/pocket-guides/context-warehouse/warehouse-foundations) under **Long-term
modeling**. It covers the view-vs-dbt decision every other skill there builds on.

Every entry in this guide is a real skill you can copy into your own agent.
