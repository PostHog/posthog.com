# Context Warehouse

Congratulations, your business is generating data which means you have people using your product.
By combining data from PostHog with external data from tools like Stripe, your CRM, or ad platform
you can answer questions that neither tool could answer on its own.

## Where to start

Getting started on your data journey? If you have a question about revenue, churn, or leads right now, **Ask a quick
question**. Each has step-by-step instructions and a Skill to build an insight end-to-end.

Beginning to need more complex data modeling? Start with **Long-term
modeling**. [Warehouse foundations](/pocket-guides/context-warehouse/warehouse-foundations) covers the view-vs-dbt decision every other Skill builds on.
