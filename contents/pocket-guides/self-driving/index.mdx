# Self-driving

PostHog tools tell you what users are doing. Self-driving acts on that data by opening pull requests that improve your product.

## Where to start

New to Self-driving? Start with [Self-driving 101](/pocket-guides/self-driving/101) on the next
page – it covers the loop, what a scout is, and how to apply use cases that follow.

Already Self-driving? Use cases in the **Contents** are scouts you can add to
your own product in one click.
