# AI Observability

</LeftPage>

<RightPage>

Your AI features don't fail loudly. They fail plausibly and confidently, with nothing that looks like an error.

Learn to see what your model does in the wild, what it costs, and whether the outputs it returns are what users want.

## Where to start

_New to AI Observability?_ Start with [AI Observability 101](/pocket-guides/ai-observability/101) to learn what data is captured on every LLM call and how to interpret it.

_Already instrumented?_ Choose a use case from the Learn sidebar. Each one includes a prompt you can run in PostHog AI to build what it describes.

Either way, they all assume your LLM calls already reach PostHog. If they don't yet, run the wizard command, or [install it yourself](/docs/ai-observability/installation):
