# AI Observability

Your AI feature works until it doesn't, and the failure mode is often hidden. 

This pocket guide is about seeing what your model actually does in the wild, what it costs, and whether the outputs it returns are what users want.

## Where to start

_New to AI Observability?_ Start with [AI Observability 101](/pocket-guides/ai-observability/101) on the next page – it explains what data is captured on every LLM call and how to interpret it.

_Already instrumented?_ The use cases in **Contents** each include a prompt you can run in PostHog AI to build the thing the guide describes.

Either way, they all assume your LLM calls already reach PostHog. If they don't yet, run the wizard first or [install it yourself](/docs/ai-observability/installation):
