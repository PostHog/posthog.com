# Triage issues automatically

An assignment rule matches on the exception's properties and assigns the issue to a role or a teammate when the issue is created <SeeFig n={1} />. To assign issues to a team, create a role for that team in your organization settings.

Rules run during ingestion, after <Term name="source map">source maps</Term> have been applied, so they match against the unminified <Term name="stack trace" />. A rule on the exception's source file can assign issues from files under `checkout/` to the Payments role. The first rule that matches assigns the issue, so put your most specific rules first.

Once you [connect](/docs/error-tracking/integrations) GitHub, GitLab, Linear, or Jira, you can create an issue there from the PostHog issue page. The new issue includes the stack trace and a link back to PostHog, where whoever picks it up can see every exception and the people it hit <SeeFig n={2} />.

PostHog AI can group your recent exceptions by source file and URL path, and suggest a rule for each group.
