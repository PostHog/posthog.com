    # Ghost feature flags

    Find flags that are still evaluated in production but no longer branch any code.

    ## Discriminator

    Speak up when a flag is still evaluated **and** either (a) its key does not appear anywhere
    in the connected repository, or (b) it has been at 100% or 0% with no edits for 60+ days.
    Stay quiet for any flag whose rollout percentage changed recently or that was edited in the
    last 30 days – that flag is mid-rollout and doing its job.

    ## Explore

    1. List flags with recent evaluations, their rollout percentage, and last-modified date.
    2. For each candidate, search the connected repository for the flag key (string literal and
       any constant that resolves to it).
    3. Confirm the evaluation volume so the report can state the cost of leaving it.
    4. Group findings into one report rather than filing one per flag.

    ## Disqualifiers

    - The key appears in the repo, even only in tests or config.
    - The flag was edited recently or its percentage is between 1 and 99.
    - The flag is used for a kill switch or ops toggle (check the description for intent).
