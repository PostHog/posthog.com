You write every email in the same editor: transactional emails, broadcasts, and the emails in an automation. Type, press `/` to add a block, and style it in the panel on the right.

The block editor is rolling out, so your project might still open emails in the old editor. To switch back for yourself, click **Use old editor**.

## Add blocks

Press `/`, or use the toolbar on the left, to add:

- Text, headings, bullet and numbered lists, and quotes
- Images, buttons, dividers, and spacers
- Sections and columns, which stack on phones
- Custom HTML, for anything else
- An unsubscribe link

Drag a block by its handle to move it, or use its menu to duplicate or delete it.

## Style it

Click **Style** to set the page: the font, colors, width, and padding. Select a block to style only that block, such as a button's color and hover color, or a section's background.

## Personalize it

Click `{x}` to add a variable, such as the person's first name, or type `{{`. Variables use [Liquid](/docs/workflows/email/liquid), so add a default for people who don't have the property:

```liquid
{{ person.properties.first_name | default: 'there' }}
```

To show a block to only some people, go to **Who sees it** and click **Show only when…**, then add a condition such as `person.properties.plan == 'paid'`. Under **Screens**, you can also show a block on desktop or phones only.

## Check it before it sends

- **Preview** shows the email on desktop or a phone. Pick a person to fill in the variables.
- **HTML** shows the HTML that sends, so you can copy it.
- **Plain text** shows the plain-text version, which PostHog writes for you from the email.

Send a test to yourself from the transactional email, broadcast, or automation.

## Reuse it

Click **Save as new template** to save an email to your library, under **Templates** > **Email templates**. Start new emails from it with **Start from template**. Most templates from the old editor open in the new one, and opening a template doesn't change what it sends. See [template library](/docs/workflows/email/library).

To get a first draft, ask [PostHog AI](/docs/posthog-ai) or your coding agent over [MCP](/docs/workflows/mcp): "Write a welcome email for new signups." Its drafts open in the editor like any other email.

## Bring your own HTML

Add a **Custom HTML** block for a piece of HTML that the blocks can't make. An email whose HTML comes from outside the editor, such as a template that you import from another tool or create over the API, sends exactly as written. To write the email in code instead, use [React Email](/docs/workflows/transactional/from-code#react-email) and send it from your [server](/docs/workflows/installation).
