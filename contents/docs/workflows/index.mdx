Workflows is PostHog's no-code, drag-and-drop tool for automating processes and sending messages to your users. You decide when a workflow is triggered, who it reaches, and what happens at each step – triggers, delays, audience splits, message sends, and PostHog actions.

Because workflows run on the same events and person properties you already send to PostHog, you can act on real product behavior instead of a separate marketing dataset. Any [real-time destination](/docs/cdp/destinations) in PostHog can be dropped into a workflow as a dispatch step, so one tool covers both messaging and automation.

## Where you can use it

You build and launch workflows in the PostHog web app. MCP and the API are for scripting, reviewing, and automating that same work from outside the app.

## Where its data comes from

A workflow is only as good as what it can trigger on and who it can reach. Three things feed it: the events and person data already in your project, the channels you connect, and the templates and opt-out rules that decide what gets sent to whom.
