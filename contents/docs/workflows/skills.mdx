PostHog ships agent skills that teach your coding agent how to send transactional email, design email templates, build workflows and broadcasts, measure how an email performs, and move off Customer.io. The skills work through the [PostHog MCP server](/docs/workflows/surfaces/mcp), and they're the same skills PostHog's own agents run.

## Set up

1. [Connect the PostHog MCP server](/docs/workflows/surfaces/mcp). The AI plugin in step 2 does this for you.

2. Install the [PostHog AI plugin](https://github.com/PostHog/ai-plugin). It bundles every PostHog skill and keeps them up to date. Its README covers installation in Claude Code, Codex, Cursor, and Gemini CLI.

<CalloutBox icon="IconInfo" title="Want the skills directly?" type="fyi">

Every PostHog skill also ships as `skills.zip` on the [latest skills release](https://github.com/PostHog/posthog/releases/tag/agent-skills-latest). The zip holds ready-to-use `SKILL.md` directories that you can drop into your agent's skills folder, such as `.claude/skills/` for Claude Code.

</CalloutBox>

Each skill's description tells your agent when to load it. Ask "send our password reset email through PostHog", and your agent loads `sending-transactional-emails` without you naming it.

## Example prompts

| Ask your agent | Skill it loads |
| --- | --- |
| "Send password resets from our Node backend with PostHog" | `sending-transactional-emails` |
| "Design a launch email for the new editor in our brand colors" | `designing-email-templates` |
| "Send it Tuesday at 9am to everyone on the old editor" | `building-workflows` |
| "Build an onboarding sequence: a welcome email at sign-up, and a nudge two days later if they haven't created a project" | `building-workflows` |
| "How did last week's product update do, and who upgraded after opening it?" | `measuring-email-performance` |
| "Move our Customer.io campaigns into PostHog" | `migrating-from-customer-io` |
