## Where knowledge comes from

Every answer comes from sources you add or turn on.

<SurfaceCards columns={3}>

<SurfaceCard icon="IconPencil" color="purple" title="Text" url="/docs/business-knowledge/sources#text" cta="Add text">
Paste a policy, an FAQ, or any other text. Edit the source when the text changes.
</SurfaceCard>

<SurfaceCard icon="IconGlobe" color="blue" title="URL" url="/docs/business-knowledge/sources#url" cta="Add a URL">
Index a public page, a sitemap, or a crawl of one site, and refresh it on a schedule.
</SurfaceCard>

<SurfaceCard icon="IconUpload" color="orange" title="File" url="/docs/business-knowledge/sources#file" cta="Upload a file">
Upload a PDF, DOCX, Markdown, CSV, or plain text file.
</SurfaceCard>

<SurfaceCard icon="IconSupport" color="teal" title="Learned from support" url="/docs/business-knowledge/learn-from-support" cta="Learn from support">
Reusable answers from resolved Support tickets, once you turn on learning.
</SurfaceCard>

<SurfaceCard icon="IconGithub" color="seagreen" title="GitHub" url="/docs/business-knowledge/github" cta="Connect a repository">
Finds files by name and README in repositories you select. Your code is not indexed.
</SurfaceCard>

</SurfaceCards>

## Use cases

- **A customer asks about refunds.** Support drafts the reply from the refund policy you pasted or the page you indexed.
- **A teammate asks which plan includes a limit.** PostHog AI answers from your pricing page.
- **Every reply needs the same tone.** Turn on **Always include in replies** for your tone guide, and every answer includes it.
- **Your docs change.** A URL source on a daily refresh picks up the new pages.
- **Your team answered the same question last week.** With [Learn from support](/docs/business-knowledge/learn-from-support) on, PostHog reuses that answer.
- **Your handbook lives in GitHub.** Select the repository, and agents find the file by name and read it.

Answers stay empty until two checks pass. See [Turn on AI data processing](/docs/business-knowledge/ai-data-processing).
