Business knowledge stores the facts PostHog uses when it answers questions about your business. PostHog AI, Support, and the Business knowledge MCP tools all read the same sources.

## Where knowledge comes from

| Source | What you add | Guide |
| --- | --- | --- |
| Text | A policy, an FAQ, or any other text you paste | [Text](/docs/business-knowledge/start#text) |
| URL | A public page, a sitemap, or a crawl of one site | [URL](/docs/business-knowledge/start#url) |
| File | A PDF, DOCX, Markdown, CSV, or plain text file | [File](/docs/business-knowledge/start#file) |
| Learned | Reusable answers from resolved support tickets | [Learn from support](/docs/business-knowledge/learn-from-support) |
| GitHub | Selected repositories. File names and the README are searched, then a file is read. The code isn't indexed. | [GitHub repositories](/docs/business-knowledge/github) |

## Use cases

- A customer asks for your refund rules. The reply comes from the refund policy you pasted or from the page you indexed.
- Someone asks PostHog AI which plan includes a limit. The answer comes from your pricing page.
- Every reply should follow the same tone. Turn on **Always include in replies** for that source.
- Your docs site changes. A URL source on a daily refresh picks up the new pages.
- A human resolved the same support question last week. With [Learn from support](/docs/business-knowledge/learn-from-support) on, that answer can be reused.
- The handbook lives in GitHub. Select that repository and an agent can find the file by name, then read it.

## Before answers can use a source

Two checks have to pass.

1. Approve **AI data processing** for the organization. Organization owners and admins do this under organization settings, in **AI service providers**. Until that's on, PostHog doesn't send source text to a model, so documents stay unchecked and search leaves them out. The Playground also refuses a question until this is on.
2. Wait for the content check on each document. Search leaves a document out until that check marks it safe, and leaves out a document marked unsafe. See [Content checks](/docs/business-knowledge/start#content-checks).

Keyword search works after the content check. Semantic search is built in the background and can take up to an hour after that. The source status shows **indexing** during that window.
