Business Knowledge is what PostHog knows about your company: your policies, your pricing, your docs, and the answers your team already gave. PostHog AI, Support, and your own agents read the same sources, so a fact you add once is available everywhere.

Answers stay empty until [two requirements](/docs/business-knowledge/requirements) are met, so start there.

<OSButton variant="primary" asLink to="/docs/business-knowledge/start">Get started</OSButton>

## Questions it answers

- A customer asks about your refund rules. Support drafts the reply from the refund policy you pasted.
- A teammate asks PostHog AI which plan includes a limit. PostHog AI answers from your pricing page.
- Every reply must use the same tone. Turn on **Always include in replies** for your tone guide.
- Your docs site changes. A URL source that refreshes every day picks up the new pages.
- Your team answered the same support question last week. With [Learn from support](/docs/business-knowledge/learn-from-support) on, Support can reuse that answer.
- Your handbook lives in GitHub. [Connect that repository](/docs/business-knowledge/github), and answers can find the right file by name and read it.

## Types of sources

| Source | What you add | Guide |
| --- | --- | --- |
| Text | A policy, an FAQ, or any other text you paste | [Add text](/docs/business-knowledge/sources#add-text) |
| URL | A public page, a sitemap, or a crawl of one site | [Add a URL](/docs/business-knowledge/sources#add-a-url) |
| File | A PDF, DOCX, Markdown, CSV, or plain text file | [Upload a file](/docs/business-knowledge/sources#upload-a-file) |
| Learned | Reusable answers from resolved support tickets | [Learn from support](/docs/business-knowledge/learn-from-support) |
| GitHub | Repositories you select. Answers search file names and READMEs, and then read a file. The code isn't indexed. | [GitHub repositories](/docs/business-knowledge/github) |
