The Playground shows what Business Knowledge holds right now, and what's missing. Ask a question a customer or teammate would ask. The answer uses only the sources in this project.

If the answer cites a source, that fact is already in Business Knowledge. If it can't find the fact, add a source and ask again.

Open [**Business Knowledge**](https://app.posthog.com/business-knowledge/playground) and choose the **Playground** tab.

Your chats are visible to you. They're grouped by when they were last used: today, yesterday, the last 7 days, the last 30 days, and older.

## Ask a question

Type a question and submit it. The placeholder is **Ask anything about your business using this project's business knowledge**.

The Playground needs [AI data processing](/docs/business-knowledge/requirements) approved for the organization. If it's off, the request is refused with: `Enable AI data processing before asking another question.`

## What the answer is allowed to read

The answer is limited to this project's Business Knowledge.

- It searches your sources.
- It can read more of a document around a matching passage.
- If [GitHub repositories](/docs/business-knowledge/github) are selected and the document search returns nothing, it can search file names and README text in those repositories, then read one file.

The thread shows each of those steps: **Searched business knowledge**, **Read document context**, **Searched repositories**, and **Read file**.

Text marked as learned from support is team practice from a resolved ticket, not a page you uploaded.

A source with **Always include in replies** is included even when it doesn't match the question, after the same content check as search.

## When an answer is wrong

The Playground doesn't change a source. Use the thread to see which step produced the answer, then fix that source and ask again.

1. Open the source the answer used.
2. Edit a text source, refresh a URL source, or delete a file source and upload it again. See [Edit or delete a source](/docs/business-knowledge/sources#edit-or-delete-a-source).
3. For a learned answer, edit or delete that learned source. See [Learn from support](/docs/business-knowledge/learn-from-support).
4. Ask the question again.

A source with **Always include in replies** is in every answer. Turn it off, or edit it, when that text is what made the answer wrong.
