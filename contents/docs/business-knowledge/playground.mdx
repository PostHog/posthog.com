The Playground shows what Business Knowledge holds right now, and what's missing. It has two tabs: **Chat** checks the answer a customer or teammate would get, and **Search** checks that a source is found at all.

Open the [**Playground**](https://app.posthog.com/business-knowledge/playground) tab in Business Knowledge. Only you can see your chats. The Playground needs [AI data processing](/docs/business-knowledge/ai-data-processing) turned on.

## Chat

Ask a question a customer or teammate would ask. If the answer cites a source, that fact is already in Business Knowledge. If it can't find the fact, add a source and ask again.

Open **Looked through business knowledge** under an answer to see each step it took. Open a step to see the chunks it returned. A chunk from a source the answer cited is tagged **Cited**.

The chunks under an answer load again when you open them. If your sources changed after the answer, they can differ from what the answer used.

### What the answer reads

The answer uses only this project's Business Knowledge:

- Your sources, plus more of a document around a matching passage.
- [GitHub repositories](/docs/business-knowledge/github) you selected, when your sources have nothing. It searches file names and README files, then reads one file.
- Every source set to **Always include in replies**, even when it doesn't match the question.

### When an answer is wrong

The Playground doesn't change a source. Use the thread to see which step produced the answer, then fix that source and ask again.

1. Open the source the answer used.
2. Edit a text source, refresh a URL source, or delete a file source and upload it again. See [Edit or delete a source](/docs/business-knowledge/sources#edit-or-delete-a-source).
3. For a learned answer, edit or delete that learned source. See [Learn from support](/docs/business-knowledge/learn-from-support).
4. Ask the question again.

A source with **Always include in replies** is in every answer. Turn it off, or edit it, when that text is what made the answer wrong.

## Search

Enter a query to see the chunks that match it, ranked, without an answer. Use it to check that a source is found at all, and how high it ranks.
