Use the Playground to see what Business Knowledge knows right now, and what's missing. Ask a question that a customer or teammate would ask. The answer uses only this project's sources, so a missing or wrong answer tells you which source to add or fix.

Open the [Playground](https://app.posthog.com/business-knowledge/playground). It needs [AI data processing](/docs/business-knowledge/requirements) approved for the organization. Until it's approved, PostHog refuses each question with `Enable AI data processing before asking another question.`

Only you can see your chats. The list groups them by when you last used them.

## What the answer can read

The answer uses only this project's Business Knowledge. The thread shows each step it takes:

| Step | What it does |
| --- | --- |
| **Searched business knowledge** | Searches your sources |
| **Read document context** | Reads more of a document around a match |
| **Searched repositories** | Searches file names and README text in your [GitHub repositories](/docs/business-knowledge/github). This step runs only when the search of your sources finds nothing. |
| **Read file** | Reads one file from a repository |

Text marked as learned from support comes from a reply your team wrote on a resolved ticket, not from a source you added.

Sources with **Always include in replies** turned on are part of every answer, even when they don't match the question.

## Fix a wrong answer

The Playground can't change a source. To fix an answer, use the thread to find the source it came from, fix that source, and ask again:

1. Open the source the answer used.
2. Edit a text source, refresh a URL source, or delete a file source and upload the new file. See [Edit or delete a source](/docs/business-knowledge/sources#edit-or-delete-a-source).
3. For a learned answer, edit or delete that learned source. See [Learn from support](/docs/business-knowledge/learn-from-support).
4. Ask the question again.

If no source holds the fact, [add a source](/docs/business-knowledge/sources) that does. If an **Always include in replies** source caused the wrong answer, edit it or turn that option off.
