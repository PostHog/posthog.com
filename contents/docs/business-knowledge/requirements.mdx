PostHog AI, Support, and the Playground can use a source only after two things happen: an admin approves AI data processing for the organization, and the source passes its content check. If answers stay empty, check these two things first.

## Approve AI data processing

An organization owner or admin approves this in organization settings, under **AI service providers**.

Until it's approved, PostHog doesn't send source text to a model. Sources stay unchecked, so search returns nothing from them, and the Playground refuses each question with `Enable AI data processing before asking another question.`

## Wait for the content check

PostHog checks every document in a source, and search leaves a document out until its check marks it safe. A document marked unsafe stays out of search. See [How content checks work](/docs/business-knowledge/sources#how-content-checks-work).

Keyword search works as soon as the check passes. Semantic search is built in the background and takes up to an hour more. The source shows **indexing** until it's done, and then **ready**.
