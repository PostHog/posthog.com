<CalloutBox icon="IconFlask" title="MCP Analytics is in beta" type="fyi">

MCP Analytics is ready for production. It's in beta because we haven't set its pricing yet.

- **Pricing.** `$mcp_*` events are billed as [product analytics events](/pricing), with the same free tier. There's no separate MCP Analytics charge. We'll announce dedicated pricing before it applies.
- **Stability.** The `instrument()` API and the `$mcp_*` events and properties are stable. New capabilities ship in minor releases. Changes to existing behavior are listed in the [TypeScript](https://github.com/PostHog/posthog-js/blob/main/packages/mcp/CHANGELOG.md) and [Python](https://github.com/PostHog/posthog-python/blob/main/CHANGELOG.md) changelogs.

</CalloutBox>
