<CalloutBox icon="IconFlask" title="MCP Analytics is in beta" type="fyi">

MCP Analytics is ready for production. It's in beta because we haven't set its pricing yet.

- **Pricing.** `$mcp_*` events count toward your [product analytics](/docs/product-analytics/pricing) usage and free tier. There's no separate MCP Analytics charge. Failed calls also send `$exception` events, which count toward [error tracking](/docs/error-tracking/pricing) unless you turn them off (`enableExceptionAutocapture: false` in TypeScript, `enable_exception_autocapture=False` in Python). If we change how MCP Analytics is priced, we'll announce it before the change takes effect.
- **Stability.** The TypeScript and Python SDK APIs and the `$mcp_*` event names are stable. The TypeScript package is still `0.x`, so minor releases can change defaults. Those changes are called out in the [TypeScript](https://github.com/PostHog/posthog-js/blob/main/packages/mcp/CHANGELOG.md) and [Python](https://github.com/PostHog/posthog-python/blob/main/posthog/CHANGELOG.md) changelogs. The [Ruby SDK](/docs/mcp-analytics/installation#ruby) is experimental.

</CalloutBox>
