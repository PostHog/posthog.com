MCP Analytics captures how agents use your MCP server. Add the SDK for your server's language, and every tool call becomes a `$mcp_tool_call` event in PostHog.

## Install with the wizard

The wizard detects your server, installs the SDK, and adds the instrumentation. It supports TypeScript and Python servers, and [LLM coding agents](/blog/envoy-wizard-llm-agent) such as Cursor:

<WizardCommand command="mcp-analytics" />

## Install by hand

Choose your server's language. For tools that a web page registers, choose WebMCP:

Each page has a Markdown version for coding agents. Add `.md` to the URL, such as [`/docs/mcp-analytics/installation/python.md`](/docs/mcp-analytics/installation/python.md).

## What each SDK captures

Every server SDK sends the core events, `$mcp_tool_call` for each tool call and `$exception` for each failed call, so your insights and dashboards work across languages. The SDKs differ in which other events and features they implement:

| Feature | TypeScript | Python | Go | Ruby | Rust |
| --- | --- | --- | --- | --- | --- |
| Tool calls and failures (`$mcp_tool_call`, `$exception`) | Yes | Yes | Yes | Yes | Yes |
| Tool listings and handshakes | Yes | Yes | No | Yes | Yes |
| Resource reads | Yes | Yes | No | Yes | No |
| Unknown-tool calls (`$mcp_unknown_tool`) | No | No | Yes | No | Yes |
| `input_required` rounds (`$mcp_input_required`) | No | No | Yes | No | Yes |
| [Agent intent](/docs/mcp-analytics/intent) (`context` argument) | Yes | Yes | Yes | Yes | Yes |
| Intent fallback callback | Yes | Yes | No | Yes | Yes |
| [Model capture](/docs/mcp-analytics/events#model-capture) | Yes | Yes | Yes | Yes | Yes |
| [Conversation IDs](/docs/mcp-analytics/conversation-id) | Yes | Yes | Yes | Yes | Yes |
| [Identifying users](/docs/mcp-analytics/identifying-users) | Yes | Yes | Yes | Yes | Yes |
| [Missing capabilities](/docs/mcp-analytics/missing-capability) (`get_more_tools`) | Yes | Yes | No | Yes | Yes |
| Stateless session token | Yes | Yes | No | Yes | No |
| Custom dispatchers | Yes | Yes | Yes | Yes | Yes |
| Wizard | Yes | Yes | No | No | No |
| Support | Beta | Beta | Beta | Experimental | Experimental |

The Go and Rust SDKs send no `$identify` event.

All SDKs remove credentials and binary content from captured payloads. See [Privacy](/docs/mcp-analytics/privacy).
