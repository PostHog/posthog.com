You can use the `before_send` callback in the [web](/docs/libraries/js) and [React Native](/docs/libraries/react-native) SDKs, or the `beforeSend` callback in the [Node.js](/docs/libraries/node) SDK 6.x.x, to exclude any exception events you do not wish to capture. Do this by providing the callback when initializing PostHog and have it return a falsey value for any events you want to drop.

<MultiLanguage>

```js file=Web
posthog.init('<ph_project_token>', {
    before_send: (event) => {
        if (event.event === "$exception") {
            const exceptionList = event.properties["$exception_list"] || []
            const exception = exceptionList.length > 0 ? exceptionList[0] : null;

            if (exception && exception["type"] === "UnwantedError") {
                return false
            }
        }
        return event
    }
})
```

```javascript file=Node.js
const posthog = new PostHog('<ph_project_token>', {
    host: '<ph_client_api_host>',
    beforeSend: (event) => {
        if (event.event === '$exception') {
            const exceptionList = event.properties?.['$exception_list'] || []
            const exception = exceptionList.length > 0 ? exceptionList[0] : null

            if (exception && exception.type === 'UnwantedError') {
                return null
            }
        }
        return event
    },
})
```
