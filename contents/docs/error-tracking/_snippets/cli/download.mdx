Install `posthog-cli`:

<MultiLanguage>

```bash file=Npm

npm install -g @posthog/cli

```

```bash file=Curl

curl --proto '=https' --tlsv1.2 -LsSf https://releases.posthog.com/posthog-cli/install.sh | sh

```

```bash file=Homebrew

brew install posthog/tap/posthog-cli

```

```bash file=Cargo

cargo install posthog-cli

```

</MultiLanguage>
