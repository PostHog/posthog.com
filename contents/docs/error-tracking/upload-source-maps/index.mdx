If you serve compiled or minified code, PostHog requires source maps to generate accurate stack traces. 

If your source maps are not publicly hosted, you will need to upload them during your build process to see unminified code in your stack traces. 

<CalloutBox icon="IconSparkles" title="Set this up automatically with the wizard" type="fyi">

If you're using a JavaScript or TypeScript framework, the PostHog [AI wizard](/docs/ai-engineering/ai-wizard) can configure source map uploading for you. Run the wizard command with `upload-source-maps` appended in your project directory:

<WizardCommand command="upload-source-maps" />

Otherwise, choose your platform below for manual instructions.
