The Northpass LMS connector syncs people, courses, learning paths, and more into the PostHog data warehouse, so you can analyze them alongside your product data.

## Prerequisites

Credentials that can read the data you want to sync. PostHog only reads data, so read access is enough.

## Adding a data source

<SourceSetupIntro />

Enter your Northpass API key to sync your Northpass (Gainsight Customer Education) learning data.

You can create an API key in your Northpass admin panel under **Apps → API Access**.

You'll be asked for:

- **API key**

## Sync modes

<SyncModes />

All Northpass LMS tables are full refresh. Each sync replaces the contents of the table.

## Troubleshooting

- If the connection fails with an authorization error, the API key is wrong, expired, or has been revoked. Create a new one, then reconnect the source.
- If a table syncs no rows, the credential may not have access to that data. Check its permissions, then reconnect the source.
