The None connector syncs constituents, transactions, interactions, and more into the PostHog data warehouse, so you can analyze them alongside your product data.

## Prerequisites

Credentials that can read the data you want to sync. PostHog only reads data, so read access is enough.

## Adding a data source

<SourceSetupIntro />

Enter your Bloomerang private API key to pull your donor database, including constituents, transactions, interactions, appeals, campaigns, and funds.

Generate a private API key under **Settings → User Settings → API Keys** in your Bloomerang account. This key grants full read/write access to your Bloomerang data, so keep it secret.

You'll be asked for:

- **API key**

## Sync modes

<SyncModes />

Some None tables sync incrementally, so later runs only fetch new or updated rows. The rest are full refresh.

## Troubleshooting

- If the connection fails with an authorization error, the API key is wrong, expired, or has been revoked. Create a new one, then reconnect the source.
- If a table syncs no rows, the credential may not have access to that data. Check its permissions, then reconnect the source.
