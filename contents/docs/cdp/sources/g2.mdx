The G2 (G2.com, Inc.) connector syncs products, categories, vendors, and more into the PostHog data warehouse, so you can analyze them alongside your product data.

## Prerequisites

Credentials that can read the data you want to sync. PostHog only reads data, so read access is enough.

## Adding a data source

<SourceSetupIntro />

Enter your G2 access token to pull your product's reviews and G2's product catalog.

Create an account and generate an access token in the [G2 Developer Portal](https://my.g2.com/developers). Grant read access to the tables you want to sync:
- Products and vendors need no scope
- Reviews need the `products.reviews.read` scope

Access tokens expire one year after creation and must be regenerated.

You'll be asked for:

- **Access token**
- **G2 product ID or slug**: used to sync reviews for your product. Find it in your G2 vendor dashboard, or in your product's G2 URL.

## Sync modes

<SyncModes />

All G2 (G2.com, Inc.) tables are full refresh. Each sync replaces the contents of the table.

## Troubleshooting

- If the connection fails with an authorization error, the access token is wrong, expired, or has been revoked. Create a new one, then reconnect the source.
- If a table syncs no rows, the credential may not have access to that data. Check its permissions, then reconnect the source.
