The AppFollow connector syncs your app reviews and ratings into PostHog, so you can analyze them alongside your product data.

## Prerequisites

You need an AppFollow account where an Account Owner or Admin can generate an API token. AppFollow bills API usage against a credit balance (reviews and ratings cost more per request) and rate-limits to 1000 requests per hour per token.

## Adding a data source

<SourceSetupIntro />

When linking AppFollow, you'll need:

- **API token** – an Account Owner or Admin can generate one on the [API management page](https://watch.appfollow.io/settings/api) in your AppFollow account. The token authenticates every request via the `X-AppFollow-API-Token` header.

## Troubleshooting

- If requests fail with an authentication error, confirm the token is valid and generated by an Account Owner or Admin, then reconnect.
- If syncs fail after running successfully before, check your AppFollow credit balance, since reviews and ratings consume more credits per request.
- If you hit the rate limit of 1000 requests per hour, wait for the limit to reset, then resync.
