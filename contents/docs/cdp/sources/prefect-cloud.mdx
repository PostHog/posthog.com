The Prefect Cloud connector syncs flows, flow runs, task runs, and more into the PostHog data warehouse, so you can analyze them alongside your product data.

## Prerequisites

Credentials that can read the data you want to sync. PostHog only reads data, so read access is enough.

## Adding a data source

<SourceSetupIntro />

Enter your Prefect Cloud account ID, workspace ID, and an API key to pull your flow and task run history.

Both IDs are in your workspace URL: `https://app.prefect.cloud/account/<account ID>/workspace/<workspace ID>`.

Create an API key under [API keys in your profile settings](https://app.prefect.cloud/my/api-keys), or use a service account key on paid tiers. The key inherits the owner's permissions, so read access to the workspace is all it needs.

You'll be asked for:

- **Account ID**: for example `00000000-0000-0000-0000-000000000000`.
- **Workspace ID**: for example `00000000-0000-0000-0000-000000000000`.
- **API key**: for example `pnu_...`.

## Sync modes

<SyncModes />

All Prefect Cloud tables are full refresh. Each sync replaces the contents of the table.

## Troubleshooting

- If the connection fails with an authorization error, the API key is wrong, expired, or has been revoked. Create a new one, then reconnect the source.
- If a table syncs no rows, the credential may not have access to that data. Check its permissions, then reconnect the source.
