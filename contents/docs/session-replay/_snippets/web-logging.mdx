Console log capture is on by default for new projects. Console logs can contain sensitive information, so review what your app logs before you leave this on. You can turn it on or off in your [project settings](https://us.posthog.com/settings/project-replay#replay). To control it client-side, set `enable_recording_console_log` in the [JavaScript Web SDK config](/docs/libraries/js/config).

```js-web
posthog.init('<ph_project_token>', {
  api_host: '<ph_client_api_host>',
  defaults: '<ph_posthog_js_defaults>',
    enable_recording_console_log: true, // TIP: This is only needed if you aren't configuring session replay using the project settings toggle.
    // ... other options
})
```

> **Important:** Individual console logs are truncated at 2000 characters. The rest of the log is not sent to PostHog. When truncating a log message we add `...[Truncated]` to the message.
