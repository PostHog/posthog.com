<CalloutBox icon="IconInfo" title="Cookies being forwarded to PostHog" type="fyi">

By default, the proxy forwards all headers including cookies to PostHog. If you don't want to forward authentication cookies and headers, delete them from the request:

```js
const requestHeaders = new Headers(request.headers)
requestHeaders.set('host', hostname)
requestHeaders.delete('cookie')
requestHeaders.delete('authorization')
```

Alternatively, configure PostHog to use `localStorage` instead of cookies:

```js
posthog.init(process.env.NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN, {
  api_host: '/yourpath',
  persistence: 'localStorage'
})
```

</CalloutBox>
