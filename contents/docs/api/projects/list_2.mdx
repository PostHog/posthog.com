Returns a list of projects in your organization.

To get your organization ID, go to [**Settings** > **Organization** > **General**](https://app.posthog.com/settings/organization-details#organization-id) or use the `/api/organizations/@current` endpoint ([US Cloud](https://us.posthog.com/api/organizations/@current) | [EU Cloud](https://eu.posthog.com/api/organizations/@current)).
