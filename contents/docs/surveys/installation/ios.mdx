## Supported features

Not all survey features are available on every SDK. See the [SDK feature support matrix](/docs/surveys/sdk-feature-support) for a full comparison.

## Limitations

- Available on iOS only (`iOS 15.0+`).
- Turn on **Enable surveys** (`surveys_opt_in`) in [project survey settings](https://app.posthog.com/settings/project-surveys) before surveys load on clients.
- Conditional questions require `posthog-ios >= 3.25.0`. To render custom native UI instead of the built-in sheet, implement `PostHogSurveysDelegate`.
