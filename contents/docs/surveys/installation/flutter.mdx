## Limitations

- Android requires API `>= 23`.
- iOS requires [iOS 15.0+](/docs/libraries/ios).
- Flutter Web delegates surveys to the [JavaScript Web SDK](/docs/surveys/installation/web).
- Requires `posthog_flutter >= 5.8.0` (`5.14.0+` recommended). See [SDK feature support](/docs/surveys/sdk-feature-support) for per-feature version floors.
- Enable **Surveys** (`surveys_opt_in`) in [project survey settings](https://app.posthog.com/settings/project-surveys) and register `PosthogObserver` so `currentContext` is available when showing surveys.

## Troubleshooting

- Update your SDK. If your project has a `Podfile`, also update your Pods.
- Make sure to set the minimum platform version to iOS 15.0 in the `Runner` target's **Minimum Deployments** in Xcode, and in your `Podfile` if you have one.
- Make sure you have disabled automatic SDK initialization.
- Run a clean build if you experience issues.
- If surveys are not being displayed when triggered, make sure you have installed the [PosthogObserver](/docs/surveys/installation/flutter#install-posthogobserver).
  - Using [`navigatorObservers`](/docs/libraries/flutter#posthogobserver)
  - Using [go_router](/docs/libraries/flutter#posthogobserver)
- If you are using multiple navigation observers and encounter a log message `[PostHog] Cannot show survey: No valid context found...`, try placing `PosthogObserver` first in the list of observers. We've noticed that order sometimes matters due to potential interference.
