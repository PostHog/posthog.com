PostHog has official SDKs for web, mobile, and server-side languages, plus libraries the community maintains. Use the SDK for the language or framework your app runs on.

## SDK versions and capture v1

PostHog is moving to the [capture v1](/docs/api/capture-v1) API to improve performance.

The SDKs below support it in their latest major version. Each of these major versions has breaking changes, so read its migration guide before you upgrade.

We suggest you migrate as soon as possible, but the older major versions keep working and stay supported.

| SDK | Moves to capture v1 in | Migration guide |
|---|---|---|
| [Python](/docs/libraries/python) | `8.0.0` | [`7.x` to `8.0`](/docs/libraries/python/migration) |
| [Go](/docs/libraries/go) | `v2.0.0` | [`v1` to `v2`](/docs/libraries/go/migration) |
| [Rust](/docs/libraries/rust) | `1.0.0` | [`0.x` to `1.0`](/docs/libraries/rust/migration) |
| [Node.js](/docs/libraries/node) | `6.0.0` | [`5.x` to `6.0`](https://github.com/PostHog/posthog-js/blob/main/packages/node/MIGRATION.md) |
| [iOS](/docs/libraries/ios) | `4.0.0` | [`3.x` to `4.0`](/docs/libraries/ios/migration) |
| [Android](/docs/libraries/android) | `4.0.0` | [`3.x` to `4.0`](/docs/libraries/android/migration) |
| [Flutter](/docs/libraries/flutter) | `6.0.0` | [`5.x` to `6.0`](/docs/libraries/flutter/migration) |

The JavaScript Web SDK, React Native, and other SDKs stay on legacy capture for now. Flutter apps on the web use the JavaScript Web SDK, so they stay on legacy capture too.

For how capture v1 handles events, see the [Capture API (v1)](/docs/api/capture-v1).
