PostHog has official SDKs for web, mobile, desktop, and server-side languages, plus libraries the community maintains. Use the SDK for the language or framework your app runs on.

## SDK versions and capture v1

PostHog is moving to the [capture v1](/docs/api/capture-v1) API to improve performance.

The SDKs below support it in their latest major version. Each of these major versions has breaking changes, so read its migration guide before you upgrade.

We suggest you migrate as soon as possible, but the older major versions keep working and stay supported.

| SDK | Moves to capture v1 in | Migration guide |
|---|---|---|
| [Python](/docs/libraries/python/reference) | `8.0.0` | [`7.x.x` to `8.0.0`](/docs/libraries/python/migration) |
| [Go](/docs/libraries/go/reference) | `2.0.0` | [`1.x.x` to `2.0.0`](/docs/libraries/go/migration) |
| [Rust](/docs/libraries/rust/reference) | `1.0.0` | [`0.x.x` to `1.0.0`](/docs/libraries/rust/migration) |
| [Node.js](/docs/libraries/node/reference) | `6.0.0` | [`5.x.x` to `6.0.0`](/docs/libraries/node/migration) |

Every other SDK, including the JavaScript Web SDK and the mobile SDKs, stays on legacy capture for now.

For how capture v1 handles events, see the [Capture API (v1)](/docs/api/capture-v1).
