If you don't have a PostHog account yet, the [AI wizard](/docs/ai-engineering/ai-wizard) can start from sign-up. The setup agent opens PostHog's sign-up page in your browser. Once you've created your account, it installs the SDK in your codebase, all from one command.

If you already have a PostHog account, run the wizard without `--signup` and it logs in to your existing account instead.

## Run it

```bash
npx @posthog/wizard@latest --signup
```

The wizard opens PostHog's sign-up page in your browser. Create your account there, then approve the wizard's access to your new project. The setup agent takes it from there: it writes the project token and host into your code, installs the SDK, and instruments your code, exactly as it does for an existing account. See [how the wizard works](/docs/ai-engineering/ai-wizard#how-it-works) for what it changes in your project.

### Flags

| Flag | Required | Description |
| --- | --- | --- |
| `--signup` | Yes | Starts at PostHog's sign-up page instead of the login page. |
| `--region` | No | Where your data lives. Use `us` ([us.posthog.com](https://us.posthog.com)) or `eu` ([eu.posthog.com](https://eu.posthog.com)). |

## Things to know

### You need a browser on the same machine

Sign-up happens in your browser, so the wizard has to be able to open one. If it can't, for example over SSH or in a container, it stops and asks you to sign up in a browser first. Create your account at [us.posthog.com/signup](https://us.posthog.com/signup) or [eu.posthog.com/signup](https://eu.posthog.com/signup), then run the wizard again without `--signup`.

### Pick the right region up front

Your region is fixed when the account is created, and `us` and `eu` are separate. You can't move data between them later, so choose the one that matches where you want your data to live.

### The interactive wizard is the supported path

The wizard has a `--ci` mode, but it's turned off in published builds, and it can't sign up because it has no browser. Run the wizard interactively, which is the default.
