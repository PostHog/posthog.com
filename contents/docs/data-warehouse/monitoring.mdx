The [ELT page](https://app.posthog.com/etl) answers three questions: what stopped, what moved, and what's running.

## Needs attention

Tables that have stopped syncing come first, with the error and a link to the source. The section is hidden when nothing is wrong, so an empty page means there's nothing to fix.

Tables fed by a webhook don't appear here. A webhook table is pushed to on the vendor's schedule rather than pulled on PostHog's, so it has no last sync and can't have stopped.

## Runs

Every sync in the window you pick, newest first, with runs in progress at the top.

This answers a different question from the section above. "Needs attention" is the state a table is in right now. "Runs" is individual jobs. A table can be broken with no recent run if nothing has retried it.

## Rows synced by destination

Rows written to each destination over the window, one series per destination. A destination that stopped receiving rows shows up as a flat line.

A row that reaches two destinations counts against both, so the series stack. This matches how the rows are billed.

## Tables syncing

How many tables are switched on across every source, and how many runs are in progress. These numbers refresh every 30 seconds while the page is open.
