Experiments let you test a change against a control and find out whether it actually worked. You define variants, pick the metrics you care about, and PostHog randomizes your users, tracks their exposures, and runs the statistics – Bayesian or frequentist – so you get a real answer instead of a hunch.

Because experiments run on the same events and [feature flags](/docs/feature-flags) you already have in PostHog, you don't need new instrumentation to measure a result. Any event, [data warehouse](/docs/data-warehouse) table, or funnel you've already built can become an experiment metric, and every variant is linked to the [session replays](/docs/session-replay) of the people who saw it.

## Where its data comes from

Experiments don't collect anything new. They read the feature flag that assigns each user to a variant, the events those users go on to send, and – if you want – tables you've already loaded into the data warehouse.

## How experiments works with Self-driving

Your experiments are a signal source for [Self-driving](/docs/self-driving). A [scout](/docs/self-driving/scouts) audits the measurement rather than the result: it reads the exposure stream of every running experiment against the split, status, and flag state you configured, and files each confirmed contradiction as a [report](/docs/self-driving/reports) in your [inbox](/docs/self-driving/inbox).

This loop stops at your review on purpose. A validity threat is an investigation rather than a one-line change, so the scout files the evidence and a suggested reviewer instead of drafting a pull request. Once you've confirmed what's wrong and the fix is a code change, you can promote the report into the usual [implementation](/docs/self-driving/inbox/implementation) path, where an agent drafts the PR and you review and merge it.

Which variant is winning stays your call – the scout never comments on results. See [PostHog Desktop](/docs/experiments/surfaces/desktop) for everything it watches, and the [Self-driving docs](/docs/self-driving) for the full picture.
