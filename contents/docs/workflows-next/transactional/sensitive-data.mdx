Sign-in codes, reset links, and magic links are secrets. Mark those emails as sensitive, and PostHog handles them more carefully.

## Protect sensitive data

For a sensitive email, PostHog:

- **Keeps links unchanged.** It doesn't rewrite them for click tracking, so a token never goes through a redirect.
- **Keeps no copy.** It doesn't store the subject or body. The Log says so instead of showing the email.
- **Leaves the subject off events.** Engagement events don't carry it.

PostHog still tracks deliveries, opens, bounces, and the status.

**Templates:** turn on **Protect sensitive data** when you create the email, or on its **API** tab. You can change it any time.

**Emails your code writes:** send `sensitive`. If you leave it out, the email takes the setting of the template with the same key, or is sensitive when there isn't one. Send `"sensitive": false` for an email with no secrets, such as an order confirmation, so its clicks are tracked.

## Tracking

[Emails your code writes](/docs/workflows-next/transactional/from-code) take `tracking`:

| `tracking` | Opens | Clicks | Engagement events |
| --- | --- | --- | --- |
| Left out | On | Off when sensitive | On |
| `true` | On | On | On |
| `false` | Off | Off | Off |
| `{ "opens": …, "clicks": …, "engagement": … }` | Your choice | Your choice | Your choice |

For example, to send an email with no secrets and track its clicks:

```js file=Node.js
await posthog.emails.send({
    to: "ada@example.com",
    templateKey: "order-shipped",
    subject: "Your order shipped",
    html,
    sensitive: false,
    tracking: { clicks: true },
})
```


</MultiLanguage>

- **A sensitive email with safe links:** send `"tracking": {"clicks": true}` to count clicks and keep the other protections.
- **One link untracked:** add `data-ph-no-track` to its `<a>` tag. Use this for app deep links, which break when rewritten.
- **Clicks need opens:** `{"opens": false, "clicks": true}` is refused.

A template send uses the template's own settings, so it takes neither `sensitive` nor `tracking`.

Opens and clicks only become events when [engagement events](/docs/workflows/engagement-events) are turned on for your project.
