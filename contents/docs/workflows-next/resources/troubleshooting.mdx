## An email didn't arrive

1. **Find the send.** For a transactional email, check the [Log](/docs/workflows-next/transactional#log). For an automation, open the run on **Invocations**.
2. **Check its status.** `failed` or `bounced` comes with a reason. See [status and troubleshooting](/docs/workflows-next/transactional/status).
3. **Was it skipped?** The run's logs say why: an opt-out, a [suppressed address](/docs/workflows-next/email/suppression), the [frequency cap](/docs/workflows-next/email/frequency-cap), or no email address.
4. **Was it `delivered`?** Then the mail server took it. Check spam, and that your [domain's records](/docs/workflows-next/domain) are still in place.

To find every bounce or complaint, click the **Bounced** or **Blocked** tile on an automation's metrics. It opens its runs, with the reason for each.

## It's going to spam

- [Set up your domain](/docs/workflows-next/domain), so SPF and DKIM pass, and add a DMARC record.
- Use a real sender name and the same from address every time.
- Check your rates on **Reputation**, and read [deliverability](/docs/workflows-next/email/deliverability).

## No sender in the email step

Add one first. See [set up your domain](/docs/workflows-next/domain), or use the [test sender](/docs/workflows-next/email/test-sender) for now. Only project admins can add a sender.

## A variable is blank, or the email won't send

| Problem | Fix |
| --- | --- |
| A blank where a name should be | The person doesn't have the property. Add `\| default: 'there'`. |
| `TokenizationError` | Use single quotes inside `{{ }}`. |
| `expected "\|" before filter` | A property starts with `$`. Use `person.properties['$email']`. |
| `Total variable size ... exceeds 5KB limit` | Save only the field you need with a result path, not the whole response. |

See [Liquid and variables](/docs/workflows-next/email/liquid).

## An automation won't turn on

PostHog checks every step before it turns on, and lists what's missing, such as a trigger event or an email address. You can save a draft that isn't finished.

## A batch run failed with nobody in it

Finding the audience timed out before anyone was added. Narrow the filters and run it again. If it keeps happening, [contact support](https://app.posthog.com/#panel=support) with the automation and the time.

## I need to stop it now

Cancel runs from **Invocations**. Turning an automation off doesn't stop people already in it. See [test and debug](/docs/workflows-next/automations/debug#stop-runs).

## Push notifications aren't arriving

Check that the device registered with the PostHog SDK, that the channel's keys are valid, and, for APNs, that **Environment** matches your app build. See [push notifications](/docs/workflows-next/push).

## Still stuck?

Ask in the [community forum](/questions), or [contact support](https://app.posthog.com/#panel=support) in PostHog.
