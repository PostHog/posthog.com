Install PostHog in up to three places:

- **Your server:** the SDK sends email.
- **Your app:** PostHog captures the events and people that broadcasts and automations use. If you already use PostHog for product analytics, this is done.
- **Your coding agent:** the MCP builds your emails and reports how they did.

## Send email from your server

> Sending from code is rolling out. If your project doesn't have it yet, the wizard tells you, and the API returns `404`.

Run the wizard from your server project. It installs the SDK, adds your secret API key, and adds the first send.

Or install it by hand:

| SDK | From version | Guide |
| --- | --- | --- |
| Node.js | 5.61.2 | [Node.js](/docs/workflows-next/installation/node) |
| Python | 7.81.2 | [Python](/docs/workflows-next/installation/python) |
| Go | Any v2 release, or 1.40.0 on v1 | [Go](/docs/workflows-next/installation/go) |
| .NET | 2.20.0 | [.NET](/docs/workflows-next/installation/dotnet) |
| Rust | `posthog` 1.0.0, or `posthog-rs` 0.31.0 | [Rust](/docs/workflows-next/installation/rust) |
| Ruby | 3.30.0 | [Ruby](/docs/workflows-next/installation/ruby) |
| Elixir | 2.20.0 | [Elixir](/docs/workflows-next/installation/elixir) |
| PHP | 4.22.0 | [PHP](/docs/workflows-next/installation/php) |

For another language, use the [API](/docs/workflows-next/installation/api). A send needs your secret API key, so send only from your server. The browser and mobile SDKs can't send email.

## Capture events from your app

Install PostHog in your app or site. Its events can start an automation, such as a welcome email on `signed_up`. Its person properties choose who gets a broadcast. [Identify](/docs/product-analytics/identify) each user and set their `email` person property, so PostHog knows where to send.

## Connect your agent

The [PostHog MCP](/docs/workflows-next/mcp) lets Claude Code, Cursor, Codex, and other agents write emails, build broadcasts and automations, [move you off another provider](/docs/workflows-next/migrate), and report how each email did. Your agent saves its changes as drafts, and you publish them.
