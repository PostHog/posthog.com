---
title: Events data retention
---

PostHog keeps your events for a period that your plan sets. Organization admins can also set a shorter retention window to control how long events are kept.

This page describes general data retention rules, with the following exceptions:

- [Session recording retention](/docs/session-replay/recording-retention)
- [AI events](/docs/ai-observability/data-retention) for AI Observability
- [Data deletion tools](/docs/privacy/data-storage#data-deletion)

## Your retention period

Your plan sets the maximum retention period:

| Plan       | Events data retention |
| ---------- | --------------------- |
| Free       | 1 year                |
| Paid plans | 7 years               |

These are the longest windows your plan allows. Organization admins can set a shorter window – see [custom retention settings](#custom-retention-settings) below.

Retention applies on PostHog Cloud only. A self-hosted instance keeps your events until you remove them.

## What retention does to your data

When retention applies to your project:

- A query on the events table reads only the events inside the window. PostHog does not include older events in the result.
- An insight whose date range goes past the window shows a banner, so that you do not read a smaller number as a drop in your product.
- Tables in the [Data Warehouse](/docs/data-warehouse) keep all of their rows, because retention applies to the events table only.

## Custom retention settings

Organization admins can set a custom retention window that is shorter than the plan's maximum. Events older than this window are permanently deleted during the monthly cleanup and can't be restored.

### Organization-wide window

Set a default retention window for all projects in your organization under [**Settings** > **Organization** > **General** > **Events retention**](https://app.posthog.com/settings/organization-details#organization-events-retention). This window applies to every project that doesn't have its own window.

### Project-specific window

Override the organization's window for a single project under [**Settings** > **Project** > **Product analytics** > **Events retention**](https://app.posthog.com/settings/environment-product-analytics#project-events-retention). When set, the project uses its own window instead of the organization's.

If you remove a project's window, the project falls back to the organization's window. If no organization window is set either, the project uses your plan's maximum.

### Permissions and constraints

- Only organization admins can change retention windows. Project admins and members can view them but not edit.
- A window must be between 1 month (or the staff-configured minimum) and your plan's maximum.
- Saving a window requires confirmation because it triggers permanent deletion.

## Deleting data

Custom retention settings delete events older than the configured window during the monthly cleanup. This is permanent and can't be undone.

To remove data in other ways, use the tools in [controlling data storage](/docs/privacy/data-storage#data-deletion):

- Delete a person, together with their events and recordings, to answer a [right to be forgotten](/docs/privacy/data-storage#right-to-be-forgotten) request.
- Delete a project or an organization to remove all of the events in it.

To keep events for longer than your retention period, send them to your own storage with a [batch export](/docs/data-pipelines/batch-exports).
