The Amazon S3 source imports CSV, JSON Lines, and Parquet files, and Delta Lake tables, from an S3 bucket into PostHog. PostHog keeps the tables up to date on the schedule you choose, so you can query your files alongside your product data.

<SelfManagedMigration />

## Prerequisites

You need:

- An S3 bucket that contains your files.
- An AWS access key with read access to the bucket.

### Create an access key

1. Open [IAM](https://console.aws.amazon.com/iam/home) in the AWS console.
2. Under **Access management**, select **Policies** and click **Create policy**.
3. Select the **JSON** tab and paste this policy. Replace `your-bucket` with the name of your bucket:

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": ["s3:ListBucket", "s3:GetBucketLocation"],
      "Resource": "arn:aws:s3:::your-bucket"
    },
    {
      "Effect": "Allow",
      "Action": ["s3:GetObject"],
      "Resource": "arn:aws:s3:::your-bucket/*"
    }
  ]
}
```

4. Click **Next**, give the policy a name, and click **Create policy**.
5. Under **Access management**, select **Users** and click **Create user**. Enter a user name and click **Next**.
6. Select **Attach policies directly**, select the policy that you created, and click **Next**. Then click **Create user**.
7. Open the user, select the **Security credentials** tab, and click **Create access key**.
8. Select **Application running outside AWS** and click **Next**. Then click **Create access key**.
9. Copy the **Access key ID** and the **Secret access key**. AWS shows the secret only once.

> **Tip:** If you don't have data in S3 yet, you can use an ETL tool such as Airbyte, Fivetran, or Stitch to export data to the bucket in Parquet format.

## Adding a data source

<SourceSetupIntro />

When you link S3, enter:

- **Files URL**: The URL of your files. You can paste an `s3://` URI, such as `s3://your-bucket/orders/`, or an object URL from the AWS console, such as `https://your-bucket.s3.us-east-1.amazonaws.com/orders/**/*.parquet`.
- **Access key ID** and **Secret access key**: The access key that you created.

## Troubleshooting

<ObjectStorageTroubleshooting />

- **The bucket is in a different region**: Use a files URL that includes the region of the bucket, such as `https://your-bucket.s3.eu-central-1.amazonaws.com/orders/`.
- **Files in archive storage classes**: PostHog can't read files in the S3 Glacier storage classes or in the archive tiers of S3 Intelligent-Tiering. Restore the files to a standard storage class, or use a files URL that doesn't match the archived files.
