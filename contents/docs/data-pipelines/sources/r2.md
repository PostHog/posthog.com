The Cloudflare R2 source imports CSV, JSON Lines, and Parquet files, and Delta Lake tables, from an R2 bucket into PostHog. PostHog keeps the tables up to date on the schedule you choose, so you can query your files alongside your product data.

<SelfManagedMigration />

## Prerequisites

You need:

- An R2 bucket that contains your files.
- An R2 API token with read access to the bucket.

### Create an API token

1. In the [Cloudflare dashboard](https://dash.cloudflare.com/), go to the R2 overview. Under **Account details**, click **Manage R2 API Tokens**.
2. Click **Create API token** and enter a name for the token.
3. Select **Object Read only** as the permission, apply the token to your bucket, and click **Create API Token**.
4. Copy the **Access Key ID**, the **Secret Access Key**, and the jurisdiction-specific endpoint URL from the credentials for S3 clients. Cloudflare shows these values only once.

![Create token](https://res.cloudinary.com/dmukukwp6/image/upload/Clean_Shot_2024_07_16_at_10_20_43_2x_97c29591fb.png)

## Adding a data source

<SourceSetupIntro />

When you link R2, enter:

- **Files URL**: The endpoint URL, followed by your bucket and the path to your files, such as `https://<account-id>.r2.cloudflarestorage.com/your-bucket/orders/**/*.parquet`.
- **Access key ID** and **Secret access key**: The credentials of the API token that you created.
