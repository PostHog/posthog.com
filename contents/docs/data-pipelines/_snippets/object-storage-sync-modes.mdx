Each table supports three sync methods:

| Sync method | What it reads | What happens to existing rows |
| --- | --- | --- |
| **Full refresh** | All the files, on each sync | The table always matches the files in the bucket. |
| **Incremental** | Only new and changed files | When you delete a file, PostHog removes its rows from the table. For a Delta Lake table, PostHog also applies deleted and updated rows. |
| **Append only** | Only new files that are at least one minute old | PostHog keeps every row that it imported before. |

Use **Incremental** for most tables. Use **Append only** for folders where files are only added, such as event logs. See [sync methods](/docs/data-pipelines/sources#sync-methods) for more about each method.

Rows that PostHog imports count toward your [data warehouse rows synced](/docs/data-warehouse/cutting-costs).
