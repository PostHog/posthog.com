PostHog's backend SDKs and API capture identified events by default. To capture anonymous events, turn off person processing for the event and use a distinct ID that isn't linked to a person profile. On the [capture v1 SDKs](/docs/libraries/capture-v1), set the `process_person_profile` option to `false`. Legacy SDKs and the legacy API use the `$process_person_profile` property. For the distinct ID, generate a random value, such as a UUID, and reuse it for the rest of the visit or session instead of sharing one ID like `system` across all anonymous events. Anonymous events are stored without person properties and don't link to [groups](/docs/product-analytics/group-analytics), so group analytics doesn't count them. If the distinct ID already belongs to a person, the event is still linked to that person and counts as an identified event – it just can't update their person properties:

<MultiLanguage>

```node
client.capture({
    distinctId: 'anonymous_distinct_id',
    event: 'your_event_name',
    options: {
        process_person_profile: false,
    },
})
```

```python
posthog.capture(
    "your_event_name",
    distinct_id="anonymous_distinct_id",
    options={
        "process_person_profile": False
    }
)
```

```php
PostHog::capture([
  'distinctId' => 'anonymous_distinct_id',
  'event' => 'your_event_name',
  'properties' => [
    '$process_person_profile' => false
  ]
]);
```

```ruby
posthog.capture({
    distinct_id: 'anonymous_distinct_id',
    event: 'your_event_name',
    properties: {
        '$process_person_profile': false
    }
})
```

```go
client.Enqueue(posthog.Capture{
    DistinctId: "anonymous_distinct_id",
    Event:      "your_event_name",
    Options: posthog.NewOptions().
      Set("process_person_profile", false),
})
```

```java
posthog.capture("anonymous_distinct_id", "your_event_name", new HashMap<String, Object>() {
  {
    put("$process_person_profile", false);
  }
});
```

```rust
let mut event = Event::new("your_event_name", "anonymous_distinct_id");

event.insert_option("process_person_profile", false).unwrap();

client.capture(event);
```

```elixir
PostHog.capture("your_event_name", %{

  "$process_person_profile": false
})
```
