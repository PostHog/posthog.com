<Step title="Install OpenTelemetry packages" badge="required">

For the complete SDK reference, see the [OpenTelemetry Go docs](https://opentelemetry.io/docs/languages/go/).

```bash
go get go.opentelemetry.io/otel
go get go.opentelemetry.io/otel/sdk
go get go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracehttp
```

`otlptracehttp` is the OTLP HTTP/protobuf trace exporter. The `otlptracegrpc` module sends gRPC, so pick `otlptracehttp` to match this guide.

</Step>

<Step title="Get your project token" badge="required">

You'll need your PostHog project token to authenticate trace requests. This is the same token you use for capturing events with the PostHog SDK.

> **Important:** Use your **project token** which starts with `phc_`. Do **not** use a personal API key (which starts with `phx_`).

You can find your project token in [Project settings](https://app.posthog.com/settings).

</Step>

<Step title="Configure the SDK" badge="required">

Set up the OpenTelemetry SDK to export spans to PostHog over OTLP HTTP. Use `WithEndpointURL` so the full `/i/v1/traces` path is sent as-is.

```go
package main

import (
	"context"

	"go.opentelemetry.io/otel"
	"go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracehttp"
	"go.opentelemetry.io/otel/sdk/resource"
	sdktrace "go.opentelemetry.io/otel/sdk/trace"
	semconv "go.opentelemetry.io/otel/semconv/v1.41.0"
)

func initTracer(ctx context.Context) (*sdktrace.TracerProvider, error) {
	exporter, err := otlptracehttp.New(ctx,
		otlptracehttp.WithEndpointURL("<ph_client_api_host>/i/v1/traces"),
		otlptracehttp.WithHeaders(map[string]string{
			"Authorization": "Bearer <ph_project_token>",
		}),
	)
	if err != nil {
		return nil, err
	}

	res, err := resource.New(ctx,
		resource.WithAttributes(semconv.ServiceName("my-service")),
	)
	if err != nil {
		return nil, err
	}

	tp := sdktrace.NewTracerProvider(
		sdktrace.WithBatcher(exporter),
		sdktrace.WithResource(res),
	)
	otel.SetTracerProvider(tp)
	return tp, nil
}
```

Call `defer tp.Shutdown(ctx)` in `main` so buffered spans flush on exit.

Alternatively, configure the exporter with environment variables and call `otlptracehttp.New(ctx)` with no options:

```bash
OTEL_EXPORTER_OTLP_TRACES_ENDPOINT="<ph_client_api_host>/i/v1/traces"
OTEL_EXPORTER_OTLP_TRACES_HEADERS="Authorization=Bearer <ph_project_token>"
OTEL_SERVICE_NAME="my-service"
```

> **Note:** `WithEndpoint` sets only the host and defaults the path to `/v1/traces`. To send to the full `/i/v1/traces` path, use `WithEndpointURL` (or the per-signal `OTEL_EXPORTER_OTLP_TRACES_ENDPOINT`), as shown.

</Step>

<Step title="Create spans" badge="required">

Wrap the operations you want to measure in spans, and attach attributes for context.

```go
import (
	"context"

	"go.opentelemetry.io/otel"
	"go.opentelemetry.io/otel/attribute"
)

var tracer = otel.Tracer("my-service")

func chargeCustomer(ctx context.Context, customerID string) error {
	ctx, span := tracer.Start(ctx, "charge-customer")
	defer span.End()

	span.SetAttributes(attribute.String("customer.id", customerID))
	// ... do work ...
	return nil
}
```

</Step>

<Step title="Link spans to people and sessions" badge="recommended">

Install the optional PostHog OpenTelemetry module:

```bash
go get github.com/posthog/posthog-go/otel
```

Register the context processor on your existing provider before requests start, then wrap your HTTP handler:

```go
import posthogotel "github.com/posthog/posthog-go/otel"

tp.RegisterSpanProcessor(posthogotel.NewContextSpanProcessor())
handler := posthogotel.NewRequestContextMiddleware(existingHandler)
```

The wrapper accepts the [core request middleware options](/docs/libraries/go#request-context). Configure [`tracing_headers`](/docs/libraries/js/config#tracing-headers) for your backend hostname in the browser SDK. Put OpenTelemetry HTTP middleware outside the PostHog wrapper to enrich its existing request span. Create child spans with `r.Context()` so the processor can read the request IDs.

The bridge adds missing `sessionId` and `posthogDistinctId` attributes. Existing `sessionId` and `posthogDistinctId` attributes take precedence. Set authenticated application identity with `posthogDistinctId`. Missing IDs stay absent. The optional module keeps your existing provider, exporter, and sampler. It does not change the core SDK dependencies.

Request context expires when the handler returns or panics. Spans that already started keep their attributes. New spans from an ended request context omit its IDs. For a separate background job, start from a fresh non-request context and set the job's IDs explicitly. Manual `WithRequestContext` use has no automatic HTTP lifetime management.

</Step>
