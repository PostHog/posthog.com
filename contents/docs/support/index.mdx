Support is one inbox for every customer conversation, with the sender's [session replay](/docs/session-replay), events, and errors already attached. You see what went wrong instead of asking the customer to reproduce it.

In the API and the SDK, Support is called Conversations: the `posthog.conversations` methods, the `$conversation_*` events, and the `disable_conversations` option. The product is Support.

<CalloutBox icon="IconInfo" title="Need help with PostHog?" type="fyi">

These pages are for the Support product you run for your own customers. If you need help with PostHog itself, see [support options](/docs/support-options).

## We run our support on it

PostHog uses SupportHog for its own customer support. Enterprise and high-paying customers can have a shared Slack channel with us, or a Microsoft Teams channel if they prefer Teams. A message in a channel we mark as a support channel becomes a ticket. In any other channel with SupportHog in it, anyone in the thread, including the customer, can mention `@SupportHog`, or react with `:ticket:` in Slack.

That is the setup we recommend for B2B support. [Connect Slack](/docs/support/slack) or [connect Microsoft Teams](/docs/support/teams).

## Use cases

The same inbox covers in-app chat, a shared `support@` address, GitHub issues, and a move off Zendesk or Intercom. Recurring bugs can become [Self-driving](/docs/self-driving) pull requests you review.

## Free to use

The widget, the inbox, every channel, workflow automation, and historical imports are free. There is no ticket cap and no per-seat charge. The [AI agent](/docs/support/ai-agent) is free while it is in beta. We will set a price later, and we will tell you before any charge starts. See [pricing](/docs/support/pricing) for the limits.
