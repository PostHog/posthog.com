The core of Support is free. There is no ticket cap and no per-seat charge. You pay only for opt-in pieces, and only after we tell you the price.

## What's free

The widget, the inbox, every [channel](/docs/support/concepts/channels), workflow automation, and historical imports are free to use.

## Limits

These are product limits, not a free-plan quota. They apply on every plan.

| Limit | Value |
| --- | --- |
| Tickets | No cap |
| Seats | No per-seat charge |
| Email addresses per project | 10 |
| Email attachment size | 10 MB per file |
| Slack or Teams files re-hosted onto a ticket | 20 MiB per file, 20 files per message |
| GitHub repositories monitored | 100 |
| Widget API | 30 requests per minute per browser session or IP, and 3,600 per hour per project |
| Workflows ticket API | 120 requests per minute and 1,200 per hour per team |
| Ticket recovery emails | 3 per hour for the same email address |

## The AI agent

<CalloutBox icon="IconFlask" title="Open beta" type="action">

The [AI agent](/docs/support/ai-agent) is in beta. It is opt-in, and it is not enabled for every project. It is free while it is in beta. We will set a price later, and we will tell you before any charge starts.

</CalloutBox>

When it is on, the agent drafts replies for your team to review. You choose whether a How-to draft is sent to the customer. Diagnostic and billing drafts stay private notes.

## Self-driving

When your tickets feed [Self-driving](/docs/self-driving), any pull requests it opens are billed under Self-driving, not Support. See [Self-driving pricing](/docs/self-driving/pricing) for current prices.
