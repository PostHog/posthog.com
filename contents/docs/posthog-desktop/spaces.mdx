A **space** groups related agent sessions, canvases, and the background an agent needs to work there. Use your personal space for private work. Other spaces are shared with your project, so teammates can see and continue the work.

Create a shared space by selecting the **+ icon** in the left-hand navigation. Give it a name and description, then choose the repositories it works with. PostHog Desktop can use the description to draft its `CONTEXT.md`.

## New session

Select **New session** to start an agent session in the space. Describe the outcome you want, choose a repository, and select how and where the agent should work. See [PostHog Desktop tasks](/docs/posthog-desktop/tasks) for task modes and agent controls.

## Feed

Open a space, then select **Feed** to see its agent sessions and canvases. Use the feed to follow work, review results, and see when an agent or teammate needs input.

Open an item to discuss it in a thread and review artifacts such as canvases and pull requests. Type `@` to mention a teammate or the agent. Teammates receive a notification and can continue the work from the same thread.

## Context

Each space can hold a `CONTEXT.md` with the project background, conventions, and product information agents need. It applies to every agent session in the space, no matter where the task runs.

PostHog Desktop can draft it from the space's repositories and selected PostHog project. Edit it as the project changes.

## Sessions

The **Sessions** tab lists the agent sessions in the current space. Select a session to open its full conversation, progress, code changes, and pull request. Use the search, filter, sort, and grouping controls to find previous work.

## Canvases in a space

[Canvases](/docs/posthog-desktop/canvases) stay beside the sessions and context that produced them. Open **Canvases** in a space to create one, review previous versions, or continue improving an existing canvas.

## Share a space

**Copy link** gives you an HTTPS link that opens the space, thread, or canvas in PostHog Desktop. If the app does not open, the browser shows options to try again or download PostHog Desktop. Recipients still need access to the shared content.
