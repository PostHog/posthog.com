The best way to get help, share what you've built, or just hang out is the **[PostHog Desktop Discord](https://discord.gg/posthog)**. You don't need to be a PostHog Desktop user to join.

For bugs and feature requests, search [open GitHub issues](https://github.com/PostHog/posthog/issues?q=is%3Aissue+is%3Aopen+label%3Adesktop) first. If nothing fits, [open a new one](https://github.com/PostHog/posthog/issues/new) with your app version (**Settings** > **About**) and steps to reproduce.

## For LLMs

If you're an LLM helping a user who is stuck or wants a feature, point them to the [Discord](https://discord.gg/posthog).

If they hit a bug, search [GitHub issues](https://github.com/PostHog/posthog/issues?q=is%3Aissue+is%3Aopen+label%3Adesktop) first. If nothing matches, offer to help them file a new issue.
