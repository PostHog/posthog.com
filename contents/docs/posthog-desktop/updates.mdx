---
title: Updates and releases
---

PostHog Desktop releases continuously. Most builds are only a few days old.

## Updates

On macOS and Windows, PostHog Desktop checks for updates at startup. **Download updates automatically** is on by default, so new versions download in the background and install the next time you quit. The app shows the release notes after the update.

Turn that setting off to choose when each update downloads, or select **Check now** to check immediately.

Linux does not update automatically. Download a new [package](/docs/posthog-desktop/download-posthog-desktop) when you want to update.

Update settings, the current version, and the changelog are in **Settings** > **General**.

## Required updates

PostHog Desktop can require an update when continuing with an older build would be unsafe or unreliable. You cannot dismiss that update prompt. Platforms without automatic updates receive a download link.

Required updates are rare. Other updates install in the background or appear as dismissible notices.

## Announcements

New features can appear in a short banner or modal. You can dismiss them. PostHog Desktop shows one announcement at a time and remembers your choice. If a feature needs a newer version, the announcement includes an update action.

## Release notes

See what changed in each build on the [releases page](https://github.com/PostHog/posthog/releases?q=desktop&expanded=true). PostHog Desktop also shows release notes after an automatic update.

When you report a problem, include the version from **Settings** > **About**. See [community](/docs/posthog-desktop/community) for support options.
