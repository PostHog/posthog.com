## All platforms

<DownloadList />

Releases include macOS DMG and zip builds for Apple Silicon and Intel, a Windows NSIS installer, and Linux AppImage, .deb, and .rpm packages. Each option opens the current PostHog Desktop releases so you can choose the latest matching asset. The same page has notes for every release.

## Eligibility

Anyone can download the app. PostHog Desktop usage consumes AI credits from your PostHog organization. See [pricing](/docs/posthog-desktop/pricing) for credit pricing and the monthly free tier.

Organizations on the PostHog **startup plan** cannot use AI credits for PostHog Desktop yet. The app shows an eligibility notice instead of allowing tasks to start. You can still download the app, sign in, and browse it.

## Updates

macOS and Windows update automatically. PostHog Desktop checks at startup, downloads new versions in the background, and installs them the next time you quit. The app shows release notes after an update.

Linux does not update automatically. Download a new package when you want to update.

See [updates](/docs/posthog-desktop/updates) for required updates and release behavior.

## Open source

PostHog Desktop is open source under the MIT license. Its source is in the [`PostHog/posthog`](https://github.com/PostHog/posthog) monorepo at `products/desktop`. See [open source](/docs/posthog-desktop/open-source) for the project structure and contribution guide.

Before you report a bug, search [open desktop issues](https://github.com/PostHog/posthog/issues?q=is%3Aissue+is%3Aopen+label%3Adesktop). If there is no match, [open an issue](https://github.com/PostHog/posthog/issues/new) with your OS, app version from **Settings** > **About**, and reproduction steps.
