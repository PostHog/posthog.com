PostHog Desktop is open source under the MIT license. Its source lives in [`products/desktop`](https://github.com/PostHog/posthog/tree/master/products/desktop) in the `PostHog/posthog` monorepo.

Use the repository documentation for contributor information:

- [README](https://github.com/PostHog/posthog/blob/master/products/desktop/README.md) – Product and repository overview
- [Contributing guide](https://github.com/PostHog/posthog/blob/master/products/desktop/CONTRIBUTING.md) – Local setup, development commands, tests, and pull requests
- [Architecture guide](https://github.com/PostHog/posthog/blob/master/products/desktop/docs/ARCHITECTURE.md) – Application structure and package responsibilities
- [MIT license](https://github.com/PostHog/posthog/blob/master/products/desktop/LICENSE)

To report a bug or request a change, [open a GitHub issue](https://github.com/PostHog/posthog/issues/new).
