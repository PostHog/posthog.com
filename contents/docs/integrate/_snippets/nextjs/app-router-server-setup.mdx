For the app router, we can initialize the `posthog-node` SDK once with a `PostHogClient` function, and import it into files.

This enables us to send events and fetch data from PostHog on the server – without making client-side requests.

```js
// app/posthog.js
import { PostHog } from 'posthog-node'

export default function PostHogClient() {
  const posthogClient = new PostHog(process.env.NEXT_PUBLIC_POSTHOG_PROJECT_TOKEN, {
    host: process.env.NEXT_PUBLIC_POSTHOG_HOST,
    flushAt: 1,
    flushInterval: 0
  })
  return posthogClient
}
```

> **Note:** Next.js server code often runs in serverless functions, which can freeze as soon as the response is sent. Setting `flushAt` to `1` and `flushInterval` to `0` sends each event right away instead of batching it.
> - `flushAt` sets how many capture calls are queued before the SDK sends them in one batch.
> - `flushInterval` sets how many milliseconds the SDK waits before sending the queue.
>
> Call `posthog.shutdown()` once you're done so pending events are sent. On Next.js 15.1 and later, wrap it in [`after`](https://nextjs.org/docs/app/api-reference/functions/after) so the network request runs after the response is sent and doesn't delay it.
>
> If you run Next.js as a long-running Node server (for example `next start` on your own infrastructure), create one shared client at module level and keep the default `flushAt` and `flushInterval`. Every event then rides in a batch instead of its own HTTP request, and you call `shutdown()` only when the process exits.

To use this client, we import it into our pages and call it with the `PostHogClient` function:

```js
import Link from 'next/link'
import { after } from 'next/server'
import PostHogClient from '../posthog'

export default async function About() {

  const posthog = PostHogClient()
  const flags = await posthog.getAllFlags(
    'user_distinct_id' // replace with a user's distinct ID
  );
  after(() => posthog.shutdown())

  return (
    <main>
      <h1>About</h1>
      <Link href="/">Go home</Link>
      { flags['main-cta'] &&
        <Link href="http://posthog.com/">Go to PostHog</Link>
      }
    </main>
  )
}
```
