| SDK | Logs | Traces | Metrics |
| --- | --- | --- | --- |
| [JavaScript web](/docs/libraries/js) (`posthog-js`) | Native, `1.368.0`+ | OpenTelemetry. `posthog-js` doesn't create spans. Use `tracing_headers` to [link requests to sessions](/docs/data/sessions#automatically-sending-session-ids). | Native `posthog.metrics`, `1.399.0`+ |
| [Node.js](/docs/libraries/node) (`posthog-node`) | Native `posthog.logger`, `5.65.0`+, or OpenTelemetry | Native, `5.52.0`+ (experimental), or OpenTelemetry | Native `posthog.metrics`, `5.43.0`+ |
| [Python](/docs/libraries/python) (`posthog`) | OpenTelemetry | Native, `7.58.0`+, or OpenTelemetry | Native `posthog.metrics`, `7.23.0`+ |
| [React Native](/docs/libraries/react-native) | Native, `posthog-react-native@4.44.0`+ | OpenTelemetry | OpenTelemetry |
| [iOS](/docs/libraries/ios) | Native, `posthog-ios@3.58.0`+ | OpenTelemetry | OpenTelemetry |
| [Android](/docs/libraries/android) | Native, `posthog-android@3.46.0`+ | OpenTelemetry | OpenTelemetry |
| [Flutter](/docs/libraries/flutter) | Native, `posthog_flutter@5.27.0`+ | OpenTelemetry | OpenTelemetry |
| Any other language | OpenTelemetry | OpenTelemetry | OpenTelemetry |

"Native" means the PostHog SDK records the signal with no OpenTelemetry packages. "OpenTelemetry" means you send it with an OpenTelemetry SDK or Collector pointed at your PostHog OTLP endpoint (`/i/v1/logs`, `/i/v1/traces`, or `/i/v1/metrics`) and your project token. Every PostHog SDK also captures events natively. Prometheus exporters can send metrics through the [metrics agent](/docs/metrics/installation).
