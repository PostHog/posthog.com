The project token (sometimes called the project API key) is a **public**, client-side key listed in the ["Project token & ID" section of your project settings](https://us.posthog.com/settings/project#variables). It's the same key you use in your frontend snippet, and it's safe to expose in client-side code such as web apps, mobile apps, and CLI tools.

Unlike the [feature flags secure API key](/docs/feature-flags/local-evaluation#step-1-find-your-feature-flags-secure-api-key), the project token doesn't grant access to any sensitive data. It can only be used to send events and to evaluate flags via the public [`/flags` endpoint](/docs/api/flags).

#### How to obtain your project token

1. Go to the ["Project token & ID" section of your project settings](https://us.posthog.com/settings/project#variables).

2. Copy the value labeled **Project token**.

3. Use it to initialize a [client-side SDK](/docs/libraries), or pass it as the `api_key` in requests to the public [`/flags` endpoint](/docs/api/flags).
