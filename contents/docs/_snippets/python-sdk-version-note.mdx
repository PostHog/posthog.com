> **Note:** These docs cover version `7.x` of the PostHog Python SDK, which requires Python 3.10 or higher. Python 3.9 is no longer supported on `7.x.x` and higher — pin to the 6.x line with `pip install 'posthog<7'`, where `6.9.3` is the final release.
>
> Everything on this page works the same way on `6.9.3`. Event capture, the context API (`new_context`, `identify_context`, `set_context_session`), and `PosthogContextMiddleware` are unchanged between `6.9.3` and `7.x`, including the middleware identifying the request context from the `X-POSTHOG-DISTINCT-ID` header and falling back to the authenticated user. `7.0.0` only dropped Python 3.9 and bumped the optional LLM provider SDKs. Later `7.x` releases add what the 6.x line does not receive, such as the Celery integration and tracing header sanitization.
