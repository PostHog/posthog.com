> **CocoaPods is becoming read-only.** [CocoaPods trunk becomes read-only on December 2, 2026](https://blog.cocoapods.org/CocoaPods-Specs-Repo/), and `posthog-ios` 4.0 and later is only published through Swift Package Manager (SPM).
>
> `@posthog/react-native-plugin` 3.0 and later always resolves `posthog-ios` through SPM, including on the CocoaPods path, so upgrading the plugin is enough. See [Upgrading to `@posthog/react-native-plugin` 3.0](/docs/libraries/react-native#upgrading-to-posthogreact-native-plugin-30).
>
> Plugin 2.x pins `posthog-ios` 3.92.x on every iOS dependency path, including the hybrid and full SPM setups, so switching paths doesn't bring newer iOS SDK versions. To get `posthog-ios` 4.0 and later, upgrade to plugin 3.0.
>
> This change doesn't affect `@posthog/react-native-plugin` releases on npm or Android.
