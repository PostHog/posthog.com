> **CocoaPods is becoming read-only.** [CocoaPods trunk becomes read-only on December 2, 2026](https://blog.cocoapods.org/CocoaPods-Specs-Repo/), and `posthog-ios` 4.0 and later is only published through Swift Package Manager (SPM).
>
> `@posthog/react-native-plugin` 3.0 and later resolves `posthog-ios` through SPM by default, including on the CocoaPods path, so upgrading the plugin is enough. See [Upgrading to `@posthog/react-native-plugin` 3.0](/docs/libraries/react-native#upgrading-to-posthogreact-native-plugin-30).
>
> On plugin 2.x, CocoaPods only resolves `posthog-ios` versions already published there. To keep receiving iOS SDK updates on 2.x, use the [hybrid CocoaPods and SPM setup](/docs/libraries/react-native#cocoapods-with-posthog-ios-through-swift-package-manager) or [full SPM integration](/docs/libraries/react-native#full-swift-package-manager).
>
> This change doesn't affect `@posthog/react-native-plugin` releases on npm or Android.
