A platform for writing and managing RFCs where documents are plain Markdown stored in Git. It has inline comment threads on specific lines, a personal review queue with team assignments, and Slack digests. AI agents plug in through an MCP server – they can read, list, and draft RFCs, but are blocked from posting comments, so discussions stay human.
