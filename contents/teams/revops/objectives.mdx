## Q4 2026 objectives

This quarter, we want to finish the move to the new revenue model, make revenue the output of a funnel we can model, and make sales comp and sales data reproducible and self-serve.

1. **Move to the new revenue model (lead: <TeamMember name="Mine Kansu" />, eng lead: <TeamMember name="Marce Coll" />)**
    - Cross-check the rebuilt ARR/MRR dashboards against the old model, then close out the remaining material discrepancies: fix them or explicitly accept them.
    - Switch go/rev and internal dashboards to the new model and retire the old ones, so there is one go/rev and one IWA view.
    - Migrate investor and board reporting to the new model ahead of the next board meeting.
    - Get Finance sign-off on the model docs and the close process.

2. **Ship the ARR funnel model (lead: <TeamMember name="Mine Kansu" />)**
    - Model the funnel from org sign-up to setup to paying to revenue, cohorted by sign-up week, so revenue is the output of the funnel rather than a separate number.
    - Use it as the base for the 2027 plan, and agree one activation metric everyone quotes.

3. **Set up a reproducible sales comp process (lead: <TeamMember name="Erika Billingsley" />)**
    - Calculate attainment and commissions from source data with no manual renewal patching, starting with fixing the warehouse view behind CS comp before Q3 close.
    - Build the comp dashboards so reps and managers can see attainment without asking us.
    - Agree the payout process with Finance.

4. **Design FY27 coverage and comp (lead: <TeamMember name="Mine Kansu" />, with <TeamMember name="Erika Billingsley" />)**
    - Define the Q1 TAM experiments and get them signed off.
    - Set the pay structure per role: basis, quota form, and churn netting, then the FY27 quota and OTE tables with a per-person backtest.
    - Build the coverage and staffing model behind it: how many seats the funnel supports, and the thresholds for CSM and always-TAM coverage.

5. **Make sales data self-serve (lead: <TeamMember name="Erika Billingsley" />)**
    - Add the sales and comp tables to the semantic layer, and publish a list of sources of truth and which fields to use for what.
    - Give each sales team a defined set of metrics so nobody is flying blind.
    - Turn the recurring process questions we answer by hand into handbook pages or automations.
