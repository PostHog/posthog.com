#### Health layer <TeamMember name="Marcel Poelker" photo />
Experiments can be complex to configure, especially since we serve a wide audience from humans to agents with varying degrees of familiarity. Understanding issues an experiment has in one central layer is the foundation needed to proactively fix issues, and feeding good inputs into the creation workflow.
- Consolidate all health rules into a single layer of deterministic checks. This enables the diagnosing skill to become a thin judgment layer on top. Include the findings in the API and MCP responses that people and agents already use. <TeamMember name="Marcel Poelker" showOnlyFirstName />
- Run the health layer automatically after each scheduled recalculation, using LLM judgment where deterministic rules are insufficient. Store the findings and send signals to the self-driving inbox whenever a finding is new or worsens. <TeamMember name="Rodrigo Iloro" showOnlyFirstName />
