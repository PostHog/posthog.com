### Q4 2026 objectives

This quarter, we want agents to make better use of what PostHog already offers. We'll test where context helps, make MCP easier to use, and establish how we measure progress.

#### Goal 1: Help agents find the right context and next step (Driver: <TeamMember name="Adam Bowker" />)

Agents should use what a company already knows and help users discover what they can do with PostHog.

What we'll ship:

- Test whether giving agents relevant context from existing PostHog sources improves their answers on common tasks
- Try ways to guide MCP agents toward a useful next step and measure whether the guidance helps them complete the task

#### Goal 2: Make MCP lighter and more reliable across clients (Driver: <TeamMember name="Jake Ruth" />)

Agents spend tokens loading skills and tool schemas and wait between tool calls. We want them to get useful answers with less overhead.

What we'll ship:

- Make it easier for agents to find the tools and skills they need without loading everything up front
- Reduce the amount of context MCP consumes on common workflows and check that those workflows still work across clients
- Compare ways agents can call tools and identify where changes could make common tasks faster or more reliable

#### Goal 3: Define how we measure the team's impact (Driver: <TeamMember name="Richard Solomou" />)

We want to know whether customers are adopting MCP, whether they keep using it, and where it falls short.

What we'll ship:

- Define and baseline a small set of measures for customer adoption, repeat use, and tool reliability
- Put the measures on a dashboard and review them regularly as a team
