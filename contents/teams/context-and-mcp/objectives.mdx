### Q4 2026 objectives

We formed in September 2026. Our first objectives are temporary and focus on investigation. We will update them with specific delivery plans once we understand each problem and choose a direction.

#### Goal 1: Prove or disprove the context layer's value (Driver: <TeamMember name="Adam Bowker" />)

Before we invest in a context layer, we need evidence that it improves agent outcomes and solves a problem people care about.

What we'll ship:

- Interview 20 external users and five internal users, then synthesize what we learn
- Write a high-level request for comments (RFC) for the context layer
- Document how the context layer could unify Business Knowledge, the semantic layer, and PostHog's other context systems

#### Goal 2: Choose the right MCP architecture (Driver: <TeamMember name="Jake Ruth" />)

We need evidence that our Model Context Protocol (MCP) architecture offers the best experience for customers and agents.

What we'll ship:

- Prototype and compare promising approaches, including code execution and the current tool-based architecture
- Recommend an architecture based on what we learn
- If the current architecture remains the best option, update this objective to focus on improving it

#### Goal 3: Define metrics to measure the team's impact (Driver: <TeamMember name="Richard Solomou" />)

We need a set of metrics we can track to understand the team's impact on revenue, usage, or both.

What we'll ship:

- Define a small set of revenue and/or usage metrics that reflect the team's impact
- Document how each metric is calculated and establish a baseline
- Set up a dashboard and a regular review cadence to track progress against these metrics
