We make PostHog available wherever agents work and give those agents the organizational context they need to make better decisions. We own PostHog's [Model Context Protocol (MCP)](/mcp) surface and are exploring how agents can use the context customers already have in PostHog.

## Problems we're solving

- **Agents spend too much time figuring out how to use PostHog.** We want common tasks to take fewer steps and work reliably across clients.
- **Agents miss context that would help them do better work.** We want agents to use what customers already know and find the next useful action in PostHog.

## What we own

- **MCP** – Make PostHog available wherever agents work
- **Organizational context** – Give agents shared company context so they can make better decisions

## Working with other teams

Agents can see what happened in code or data, but they often cannot see why a decision was made, what a team is prioritizing, or what a company means by its internal language. We work with product teams to make that context useful to agents.

Come to us if you:

- Are building an integration with the PostHog MCP server or store
- Want an agent to read from or contribute to organizational context
- Want to connect a source such as Slack, GitHub, conversations, or your semantic layer
- Need help with privacy, access control, or safe context sharing between agent surfaces
