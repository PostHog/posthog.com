We make PostHog available wherever agents work and give those agents the organizational context they need to make better decisions. We own PostHog's [Model Context Protocol (MCP)](/mcp) surface and are building a shared context layer that connects what a company knows across its tools and PostHog products.

## What we own

- **MCP** – Make PostHog available wherever agents work
- **Organizational context** – Give agents shared company context so they can make better decisions

## Working with other teams

Agents can see what happened in code or data, but they often cannot see why a decision was made, what a team is prioritizing, or what a company means by its internal language. We build the shared layer that gives agents this context without each product creating its own memory system.

Come to us if you:

- Are building an integration with the PostHog MCP server or store
- Want an agent to read from or contribute to organizational context
- Want to connect a source such as Slack, GitHub, conversations, or your semantic layer
- Need help with privacy, access control, or safe context sharing between agent surfaces
