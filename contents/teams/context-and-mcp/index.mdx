We make PostHog available wherever agents work. We own PostHog's [Model Context Protocol (MCP)](/mcp) and help agents use what customers already know about their products and data.

## Problems we're solving

- **Agents spend too much time and context on MCP overhead.** We make tools and skills easier to discover on demand and reduce the amount of data each call puts into the agent's context.
- **Agents miss relevant context and useful next steps.** We test how to get the right skills, Business Knowledge, and semantic layer definitions into PostHog AI, and how to guide MCP agents when a tool call returns an empty result or an error.

## What we own

- **MCP** – Make PostHog available wherever agents work
- **Organizational context** – Give agents shared company context so they can make better decisions

## Working with other teams

We work with product teams to make their tools and knowledge useful to agents. We're also exploring what infrastructure teams could share for agent memory.

Come to us if you:

- Are building an integration with the PostHog MCP server or store
- Want an agent to read from or contribute to organizational context
- Want to connect a source such as Slack, GitHub, conversations, or your semantic layer
- Need help with privacy, access control, or safe context sharing between agent surfaces
