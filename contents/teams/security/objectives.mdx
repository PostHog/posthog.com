## Q3 2026 goals

These goals are intentionally vague to avoid disclosing sensitive information.

### Automate routine security work
- Triage vulnerabilities and threat alerts with minimal human intervention

### Improved application secrets management
- Secrets that are easier to manage, rotate, and audit

### Update packages without humans
- Dependency update PRs that merge themselves

### Speed up incident response
- Detect and contain malicious activity faster

### GitHub hardening
- Commit signing enforced org-wide
- No more SSH keys on disk
