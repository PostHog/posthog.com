# <Eyebrow>A pocket guide to</Eyebrow> Self-driving

PostHog tools tell you what users are doing. Self-driving acts on that data by opening pull requests that improve your product.

Learn how the self-driving loop works through real scouts. Each use case walks through the report a scout files, the pull request it becomes, and the scout itself, which you can add to your own product.
