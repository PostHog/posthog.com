# Triage issues automatically

Assignment rules route each new issue to the team that owns it. A rule matches on the exception's properties and assigns the issue to a role or a teammate <SeeFig n={1} />. To assign issues to a team, create a role for it in your organization settings.

Rules run at ingestion, after <Term name="source map">source maps</Term> are applied, so they match your unminified <Term name="stack trace" />. For example, a rule on the source file can send issues from `checkout/` to the Payments role. The first match wins, so put specific rules first.

To track the fix in another tool, [connect](/docs/error-tracking/integrations) GitHub, GitLab, Linear, or Jira, and create the issue from the PostHog issue page. It links back to the PostHog issue, with every exception and the people the issue impacts, and you can add the impact before you create it <SeeFig n={2} />.

PostHog AI can group your recent exceptions by source file and URL path, and suggest a rule for each group.
