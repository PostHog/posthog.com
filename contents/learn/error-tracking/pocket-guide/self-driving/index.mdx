# Self-driving

Now that Twig's exceptions flow into Error Tracking, the engineers want PostHog to be more proactive in resolving them, so they turn on <Term name="scout">scouts</Term> in self-driving. Scouts automatically look for issues, assess their impact, create a <Term name="report" /> with the impact and the fix, and even open pull requests to help the engineers resolve them.

Here are some examples of how Twig self-drives with Error Tracking:

- [Catch error spikes and stuck loops](/learn/error-tracking/pocket-guide/spikes-and-stuck-loops) ranks spikes by how many guests they affect.
- [Find the errors Twig's paying hosts hit](/learn/error-tracking/pocket-guide/errors-in-paying-hosts) reports issues concentrated in hosts who pay.
- [Connect a deploy to an error burst](/learn/error-tracking/pocket-guide/deploy-regressions) ties a new issue to the pull request that likely caused it.
- [Check whether the fix held](/learn/error-tracking/pocket-guide/verify-the-fix) reports fixes that didn't stop the error.
